# 史颉华 · 个人主页

一扇门厅。每个项目仍是自己的页面，主页只放卡片：先看见状态和三行预览，再直达原文。

卡片内容是 2026-10-26 从 Notion 项目库和各个仓库读来的快照。原文改了，改对应的模块文件。

## 运行

```bash
npm install
npm run dev
```

打开终端里的本地地址。`npm test` 检查名单和筛选，`npm run build` 做静态构建。

## 加一个项目

1. 在 `src/modules/entries/` 新建一个文件，用 `defineModule` 写出标题、一句预览、三行事实和直达链接。
2. 在 `src/modules/registry.ts` 的 `modules` 数组里登记。

主页和 `/p/项目代号` 不用再改。

## 卡片怎么走

- 点「直达」打开 Notion 或 GitHub 上的原页面。
- 点标题或「本站页面」进入站内的独立页，页上仍有直达。
- 搜索框按回车，打开当前结果里第一张卡片的原页面。按 `/` 聚焦搜索。

默认「当前」收起已完成的季度页。那些页在「季度」和「全部」里。
